# Fotos do clube

Solte aqui fotos do clube (`.jpg`, `.png`, `.webp`, `.avif` ou `.gif`). Elas aparecem numa faixa
discreta no rodapé do site e, abaixo do login, na tela de entrada. Sem fotos, nada aparece.

**O repositório é público: toda foto colocada aqui fica pública**, mesmo se apagada depois (fica
no histórico do git). Coloque só fotos que todos os presentes aceitam mostrar.

- O nome do arquivo vira a descrição da foto para leitores de tela: `encontro-de-marco.jpg` vira
  "Foto do clube: encontro de marco". Nomes de câmera (`IMG_2034.jpg`) viram só "Foto do clube".
- Reduza antes de colocar (uns 800 px no lado maior bastam): fotos de celular inteiras deixam o
  site pesado. Fotos `.heic` do iPhone não abrem no navegador; exporte como `.jpg`.
